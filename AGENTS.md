# Learning workflow

- Work through AgentLens with the user one step at a time; do not implement the entire learning roadmap at once.
- In the initial progress message before making changes, list the files the user should read to understand the planned changes, in reading order, with a brief explanation of what to focus on in each file. Include planned new files when relevant.
- In the final response, update the reading list if the actual changes differ from the initial plan.
- When providing commands, explain their purpose and each flag and positional argument, including punctuation such as the Docker build context `.`. Describe the expected result instead of just listing commands.
